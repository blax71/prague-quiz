# Prague Challenge PWA

Minimal PWA for iPhone/Home Screen use. No frameworks and no external JS libraries.

## Install on iPhone
1. Publish this folder to a GitHub Pages site using HTTPS.
2. Open the site in Safari on iPhone.
3. Share -> Add to Home Screen.
4. Launch "Prague Quiz" from the Home Screen.

## Notes
- Google Maps is the primary navigation button; Apple Maps is included as a fallback.
- Progress is stored in localStorage.
- Photos are stored locally in IndexedDB and are not uploaded by the app.
- The route contains St. Nicholas Church twice, so stop 7 is kept as a separate bonus quiz to preserve the 9 stops from the supplied Google Maps route.
- The supplied route is a walking route.
